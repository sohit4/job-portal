PART 1: PROJECT SYNOPSIS (Project Report, College/Viva Submission ke liye)
--------------------------------------------------------------------------------

1. PROJECT TITLE:
   Job Hunt - An Online Recruitment & Job Application Tracking Portal

2. ABSTRACT:
   Job Hunt is a modern, responsive, and secure full-stack web application designed 
   to bridge the communication and hiring gap between Job Seekers (Candidates) 
   and Recruiters (Employers). Built on the MERN stack (MongoDB, Express.js, 
   React.js, Node.js), this platform offers seamless job discovery, real-time 
   application tracking, and role-based access control. Candidates can upload their 
   resumes and track application statuses (Pending, Accepted, Rejected), while 
   employers can register companies, post job openings, review applicants, and 
   manage hiring decisions.

3. PROBLEM STATEMENT:
   - Existing traditional recruitment processes often rely on disjointed email threads 
     and physical paperwork, causing severe communication delays.
   - Job applicants rarely get visibility into their application lifecycle and status.
   - Small and medium enterprises lack cost-effective, easy-to-use platforms to manage 
     vacancies and screen applicant resumes effectively.

4. PROPOSED SOLUTION:
   - Centralized, dual-role architecture: Job Seeker & Recruiter.
   - Comprehensive Job Discovery: Search by keywords, location, and salary filters.
   - Cloud Document Storage: Secure profile picture and PDF resume management using Cloudinary.
   - Transparent Lifecycle: Live status badges (Pending, Accepted, Rejected) for applicants.
   - Modern User Experience: Lightning-fast Vite-powered React UI styled with Tailwind CSS.

5. TECHNOLOGY STACK:
   - Frontend:
     * React.js (v19) with Vite
     * Tailwind CSS & Radix UI (shadcn-style UI components)
     * Redux Toolkit & Redux Persist (State Management)
     * React Router DOM (Routing)
     * Framer Motion & Lucide React (Animations & Icons)
     * Axios (API Communication)
   - Backend:
     * Node.js & Express.js (REST API architecture)
     * JSON Web Tokens (JWT) & Cookie-Parser (Authentication)
     * Bcrypt.js (Password hashing & security)
     * Multer & DataURI (File parsing)
     * Cloudinary SDK (Cloud-based storage for resumes & images)
   - Database:
     * MongoDB & Mongoose (NoSQL database with schema modeling)

6. CORE MODULES & FEATURES:
   A. Authentication & Security:
      - Role selection during registration (Student/Job Seeker vs Recruiter).
      - Encrypted passwords and JWT token authentication stored in HttpOnly cookies.
      - Protected frontend and backend routes preventing unauthorized access.

   B. Job Seeker Module:
      - Interactive Landing Page with job carousels and hero search.
      - Filterable Jobs Listing page (Filter by Location, Industry, Title).
      - Job Details view with company info, requirements, and positions count.
      - 1-Click Apply to Jobs.
      - Candidate Profile Dashboard: Bio, Skills list, contact info, and PDF resume upload.
      - "Applied Jobs" tracking table with instant status updates.

   C. Recruiter Module:
      - Company Registration & Branding (Logo, Website, Location, Description).
      - Job Posting interface with custom skill tags, salary ranges, and job types.
      - Recruiter Dashboard displaying posted jobs and applicant counts.
      - Applicants Management Page: View candidate profile, download/view resume, 
        and update application status (Pending -> Accepted / Rejected).

7. DATABASE ARCHITECTURE (Collections):
   - Users: FullName, Email, PhoneNumber, Password, Role, Profile (Bio, Skills, Resume, Company).
   - Companies: Name, Description, Website, Location, Logo, CreatedBy.
   - Jobs: Title, Description, Requirements, Salary, Location, JobType, Position, Company, CreatedBy, Applications.
   - Applications: Job, Applicant, Status (pending | accepted | rejected), Timestamps.

8. FUTURE SCOPE:
   - AI-driven Resume Parsing and Automatic Match Scoring.
   - Real-time in-app chat between Recruiter and Applicant (Socket.io).
   - Automated email updates for status changes (Nodemailer).
   - Video interview scheduling integration.
